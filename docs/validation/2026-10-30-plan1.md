# Validation du plan 1 contre l'API OpenRouter réelle

Date : 2026-10-30. Binaire : `target/release/srtty` (branche `feat/plan-1-core`, build `cargo build --release`).
Modèle : `x-ai/grok-stt-1.0` via OpenRouter (`https://openrouter.ai/api/v1`). Médias LibriVox (domaine public) : « La Barbe bleue » (663,8 s) et « Les Précieuses ridicules » (3474,6 s).

## Conditions

- Config temporaire (`SRTTY_CONFIG`) : fournisseur `openrouter`, `api_key_env = "OPENROUTER_API_KEY"`, modèle `x-ai/grok-stt-1.0`. Cache temporaire via `XDG_CACHE_HOME`. Tout est sous `/tmp/srtty-val/`, rien dans le dépôt.
- La clé est lue dans un fichier privé par un script enveloppe (`run.sh`), à l'intérieur du processus ; elle n'est ni affichée ni écrite. Dans les commandes ci-dessous, `srtty` désigne cette enveloppe.
- Validateur SRT strict maison (`python3 -I validate_srt.py`) : numérotation 1..N consécutive, ligne de timestamps `^\d{2}:\d{2}:\d{2},\d{3} --> \d{2}:\d{2}:\d{2},\d{3}$`, début < fin, débuts strictement croissants, blocs séparés par une seule ligne vide, aucun texte vide.
- Écarts par rapport au brief (décisions du contrôleur) : pas de `mpv` (contrôle de synchro par comparaison avec les timings Deepgram du spike), pas de coupure réseau (SIGINT puis reprise depuis le cache), pas de `import srt`.
