# Validation du plan 4 : backend local whisper-rs

Date : 2026-10-31. Branche `feat/plan-4-local-whisper`, binaire `cargo build --release --features local`. **Coût d'API : 0 $.**

Téléchargements :
- `ggml-tiny.bin` (78 Mo), pour les tests qui demandent un modèle ;
- `ggml-base.bin` (148 Mo), téléchargé par `setup` ;
- 11 Mo d'un second téléchargement de `tiny`, interrompu volontairement.

## Conditions

- Machine Linux x86_64, 16 cœurs, 30 Go de RAM. whisper-rs 0.16.0 (whisper.cpp 1.8.3), CPU seulement.
- Config, cache et données sont isolés dans `/tmp/srtty-plan4` (`SRTTY_CONFIG`, `XDG_CACHE_HOME`, `XDG_DATA_HOME`).
- Le tableau de bord et `setup` tournent dans le pseudo-terminal émulé par `pyte` du plan 3. Le harnais gagne des étapes « attendre un texte à l'écran, puis envoyer des touches », pour piloter les menus d'inquire, et note l'heure de sortie.
- Référence pour les timestamps : le SRT OpenRouter (Grok) de « La Barbe bleue » produit au plan 3, et les débuts réels de la parole mesurés avec `silencedetect` (-35 dB, 0,15 s).

## Scénario 0 : frontière du build

- **Sans feature** :
  - `cargo tree -i whisper-rs-sys` échoue (« did not match any packages ») ;
  - `cargo build --release` dans un répertoire cible vierge prend 40 s, et aucun script de build whisper n'est compilé.
- **Avec `--features local`** :
  - le build de whisper-rs-sys à froid prend environ 30 s (cmake 3.28.3, clang 18.1.3, gcc 13.3) ;
  - `cargo tree --target aarch64-apple-darwin --features local` montre `whisper-rs-sys feature "metal"`.
- Tests : 271 unitaires et 25 de bout en bout sans feature. Avec `--features local` et le modèle tiny : 316 unitaires, 24 de bout en bout et 6 tests locaux. fmt et clippy `-D warnings` sont propres dans les deux configurations.

## Scénario 1 : `setup` local de bout en bout

- Le menu des fournisseurs propose `Local Whisper (offline, runs on this machine)`. Le catalogue liste 5 modèles, `large-v3-turbo-q5_0` en premier.
- J'ai choisi `base`. Après la confirmation `Download ggml-base.bin (148 MB) from Hugging Face to …?`, la progression `Downloading ggml-base.bin: 52% (78 MB of 148 MB)` s'affiche.
- Le SHA-256 du fichier obtenu, vérifié par `sha256sum`, est identique à la valeur figée (`60ed5bc3…`).
- Le test de l'extrait affiche `✔ Test passed: 97 words in 2.5 s (language: fr).`
- La config écrite contient `default_provider = "local"`, `kind = "local"` et un `model_path` absolu. Elle sert telle quelle aux scénarios suivants.
- **Ctrl-C pendant le téléchargement** (`tiny`, à 13 %) donne `× interrupted` et le code 130. Aucun `.part` ne reste dans le dossier des modèles, et la config n'a pas changé.
- **Modèle déjà présent** : `(downloaded)` dans le menu, puis `Checking ggml-base.bin…` et `✔ ggml-base.bin is already downloaded.`. Le hash de 148 Mo est trop rapide pour qu'on puisse l'interrompre ; le Ctrl-C est tombé sur la question suivante, et l'a interrompue (code 130).

## Scénario 2 : « La Barbe bleue » hors ligne, tableau de bord

- Le run est lancé sous `unshare -rn` (aucune interface réseau), avec `--format srt,vtt,txt`. Il fait 664 s d'audio en 2 morceaux.
- Le tableau de bord ne change pas :
  - le titre affiche `ggml-base.bin` ;
  - les morceaux affichent `✔ 936 words 28.8 s` et `✔ 1165 words 31.6 s` ;
  - la ligne de stats affiche `9.9× realtime` et aucun coût.
- L'avertissement `language detected as fr; pass --language to force another one` s'imprime au-dessus du cadre.
- Le récapitulatif annonce 182 sous-titres, `model ggml-base.bin` et `cost n/a`. Les trois fichiers sont écrits.

## Scénario 3 : jonctions (critère §6)

- J'ai comparé le run découpé (coupe à 299,9 s, au milieu d'un silence) avec un run en un seul morceau (`--chunk 10000`).
- Autour de la coupe, toutes les différences sont des substitutions de reconnaissance (`demeurait` / `a`, `grès` / `gré`), sans insertion ni suppression. **Aucun mot perdu ni dupliqué.**
- Les différences entre les deux runs se répartissent dans tout le fichier : `base` transcrit différemment selon le contexte.

## Scénario 4 : timestamps (critère §6)

Les débuts de sous-titres sont alignés mot à mot sur le SRT OpenRouter :

| Timestamps | Médiane | p90 | Sous 0,5 s | Points de contrôle (58, 180, 300, 421, 598 s) |
| --- | --- | --- | --- | --- |
| tokens whisper.cpp (`t0`) | 0,34 s | 1,01 s | 57 % | −0,73 / −0,12 / −0,14 / −0,30 / −0,40 s |
| **DTW (`t_dtw`)**, retenu | **0,07 s** | **0,16 s** | **99 %** | +0,05 / +0,05 / +0,06 / +0,12 / +0,04 s |

- Débuts réels de la parole aux points de contrôle (`silencedetect`) : 58,47, environ 180,5, 300,03, 421,45 et 598,21 s. La référence Grok en est à moins de 0,15 s.
- Sans DTW, le premier point est à −0,69 s du vrai début : les tokens de whisper.cpp sont jointifs et absorbent la pause de 0,7 s qui précède « Ce ».
- Avec DTW, le même mot tombe à 58,56 s (+0,09 s). Le plan prévoyait ce repli (décision 4), consigné en écart.

## Scénario 7 : `--json` redirigé et `NO_COLOR`

## Autres vérifications

  - texte : `no API cost: the local backend runs on this machine` ;
  - JSON : `"estimated_cost_usd":null` ;
  - aucun chargement de modèle.
- **`--speakers`** : code 1, `--speakers is not supported by the local backend; …`.
- **Binaire sans feature sur la config locale** : code 1, `the local backend is not available in this build; reinstall with: cargo install srtty --features local`.
- **`--language fr`** : 192 sous-titres, aucun avertissement de langue, comme attendu.

## Limites constatées

- `base` fait beaucoup de substitutions en français (`l'essuie` pour `l'essuya`). Pour un usage réel, `large-v3-turbo-q5_0` (574 Mo) est proposé en premier, mais je ne l'ai pas validé : téléchargement optionnel, à décider par Adrien.
- **Le cache ne dépend pas de la version de srtty.** Un transcript mis en cache avant DTW est resservi tel quel. Ce n'est pas un problème avant la première release.
- Un relancement servi par le cache ne fige aucune langue et n'affiche pas l'avertissement de langue. C'est la limite déjà notée à la décision 13.
- Le chemin « Ctrl-C pendant le hash » de `setup` n'a pas pu être exercé, car le hash de `base` est trop rapide.
- La ligne de progression garde le `^C` affiché par le terminal avant `× interrupted`.
- Metal n'a pas été testé sur cette machine Linux. C'est à la CI macOS du plan 5.

## Verdict

Le critère du §6 est tenu : `cargo build` sans toolchain C++ ; avec `--features local`, « La Barbe bleue » se transcrit hors ligne, sans mot perdu aux jonctions et avec des timestamps à moins de 0,5 s (grâce à DTW). Le tableau de bord, `--json`, `NO_COLOR`, Ctrl-C et `setup` se comportent comme prévu.
